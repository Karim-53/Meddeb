Install

  1. On the phone, tap the download link above.
  2. Open the downloaded file (from the browser's notification or the Downloads folder).
  3. The first time, Android asks to allow the browser (or the file app) to install unknown apps: Settings → Allow from this source, then go back.
  4. Tap Install.
  5. Open Meddeb. The first start takes up to a minute, and Meddeb then downloads its speech model (about 130 MB) by itself.

Updates

Meddeb looks at this website by itself (when you open About, and after 10 minutes of use). When a new version is here, the menu ☰ ends with Update 0.10 → 0.11: a tap downloads it and installs it (the first time, Android asks you to allow Meddeb to install apps). You can also install a newer file from this page over the old one. Your profile and the speech model stay.

Never uninstall to update: uninstalling deletes your profile (your recordings, marks and progress). Settings → Export profile keeps a copy first.

In the car (Android Auto)

Android Auto shows an app that does not come from Google Play only while its own Unknown sources setting is on: Settings → Connected devices → Android Auto, tap Version about 10 times and confirm, then ⋮ → Developer settings → Unknown sources.

Check the file

The SHA-256 above is the file's checksum. apksigner verify --print-certs meddeb_v….apk shows the signing certificate; Android refuses any update signed with another one.
